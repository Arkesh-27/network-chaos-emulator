# Project Requirements

## Project Title

Network Latency & Packet-Loss Chaos Emulator

## Objective

The objective is to develop a Linux-based C++ command-line application
that can simulate network problems for testing purposes.

## Functional Requirements

1. Display available network interfaces.
2. Configure artificial network latency.
3. Configure packet loss.
4. Configure jitter.
5. Display current network configuration.
6. Reset custom network configuration.
7. Provide a menu-driven interface.

## Non-Functional Requirements

1. The application should be simple to use.
2. Invalid input should be handled.
3. The program should run on Linux.
4. The source code should be modular.
5. The project should use Git for version control.

## Technologies

- C++
- Linux/Ubuntu
- Linux Traffic Control (tc)
- NetEm
- Git
- VS Code
